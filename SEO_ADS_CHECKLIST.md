# LiveDev: запуск SEO, аналитики и рекламы

## 1. Сразу после публикации

1. Проверить главную, `/uslugi/`, несколько страниц услуг и проектов на телефоне и компьютере.
2. Проверить `https://live-dev.by/robots.txt` и `https://live-dev.by/sitemap.xml`.
3. Отправить тестовую заявку и убедиться, что она появилась в админке и Telegram.
4. Не запускать рекламу, пока заявка и цели не проходят полный путь без ошибок.

## 2. Яндекс.Метрика

1. Создать бесплатный счётчик для `live-dev.by` без `https://` в поле домена.
2. Включить приём данных только с указанных адресов.
3. При необходимости включить Вебвизор, карту кликов и аналитику форм.
4. Создать JavaScript-цель с именем `lead_submit`.
5. В админке LiveDev открыть «Контакты и счётчики» и заполнить:
   - «Яндекс.Метрика ID» — только число;
   - «Цель заявки» — `lead_submit`.
6. Отправить тестовую заявку и проверить достижение цели в Метрике.

## 3. Яндекс Вебмастер

1. Добавить `https://live-dev.by/` и подтвердить владение через DNS.
2. Отправить `https://live-dev.by/sitemap.xml`.
3. Проверить индексирование, HTTPS, мобильность и диагностические сообщения.
4. Указать регион Витебск и дать ссылку на главную, где виден текст «Витебск, Беларусь».
5. Не указывать выдуманный офис. Для Яндекс Бизнеса использовать формат онлайн-компании или зоны обслуживания, если он доступен для выбранной категории.

## 4. Google Search Console и GA4

1. Создать Domain property `live-dev.by` и подтвердить её DNS-записью.
2. Отправить `sitemap.xml`.
3. Запросить индексирование главной, `/uslugi/` и основных услуг.
4. Создать поток GA4 для `https://live-dev.by/`.
5. Вставить `G-...` в поле GA4 админки. GTM при прямом подключении оставить пустым.
6. Отправить тестовую заявку и проверить событие `generate_lead` в Realtime/DebugView.

## 5. Первая кампания Яндекс Директа

1. Начать только с рекламы на поиске, без сетей и автоматического расширения площадок.
2. Создать отдельные группы по намерению пользователя:
   - разработка сайтов;
   - разработка лендинга;
   - разработка CRM;
   - Telegram Mini App;
   - Telegram-боты;
   - AI-автоматизация.
3. Каждую группу вести на соответствующую страницу `/uslugi/.../`, а не всегда на главную.
4. Разделить географию: Витебск и остальная Беларусь. Не смешивать регионы с разной ценой лида в одной группе.
5. Добавить минус-слова: бесплатно, скачать, шаблон, конструктор, курсы, обучение, вакансия, работа, зарплата, реферат.
6. Использовать только утверждения, которые можно подтвердить. Не писать выдуманные сроки, количество клиентов или гарантированные результаты.
7. Цель оптимизации — `lead_submit`.
8. Добавить UTM: `utm_source=yandex&utm_medium=cpc&utm_campaign=...&utm_content=...&utm_term=...`.
9. На первую неделю установить жёсткий дневной и недельный лимит. Не включать автоувеличение бюджета.
10. После первых данных отключать запросы без коммерческого намерения и перераспределять бюджет по реальным заявкам, а не по кликам.

## 6. Google Ads

1. Запускать после проверки конверсии в GA4 и первой посадочной страницы.
2. Создать действие-конверсию «Отправка заявки».
3. Вставить в админку `AW-...` и Conversion Label. GTM оставить пустым при прямом подключении.
4. Начать с Search campaign, отключив Display Network.
5. В настройке географии выбрать присутствующих в целевом регионе, а не просто интересующихся им.
6. Разделить услуги по группам и вести каждую на отдельную страницу.
7. Добавить те же минус-слова и UTM-метки.
8. Перед пополнением проверить доступные для белорусского платёжного профиля способы оплаты и требования подтверждения рекламодателя.

## 7. Органическое продвижение

1. Не создавать десятки одинаковых страниц с заменой одного города.
2. Добавлять реальные проекты через админку — они автоматически получают SEO URL и попадают в sitemap.
3. Дополнять проекты фактическими задачами, функциями и результатом, не раскрывая данные клиента без разрешения.
4. Публиковать полезные материалы по реальным вопросам заказчиков и связывать их со страницами услуг.
5. Получать естественные упоминания: профили компании, партнёры, каталоги, публикации и кейсы. Не покупать массовые SEO-ссылки.
6. Еженедельно смотреть запросы и индексирование в Вебмастере/Search Console; рекламные клики анализировать отдельно по UTM.
